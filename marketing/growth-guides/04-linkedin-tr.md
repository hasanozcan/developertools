# Üç pratik geliştirici rehberi

Dosya checksum’ı tutmuyor, API çıktısında Unicode kaçışları görünüyor veya UUID v4 ile v7 arasında seçim yapmak gerekiyor. Böyle durumlarda çalışan örneğin yanında sonucun ne anlama geldiğini de bilmek gerekiyor.

Geliştirdiğim DevsTools için üç kullanım rehberi hazırladım:

- SHA-256 ile dosya doğrulama: tarayıcı, PowerShell, terminal ve Python örnekleri; checksum eşleşmesinin sınırları.
- Unicode escape çözme: JSON ve JavaScript gösterimleri, emoji surrogate çiftleri ve çift kaçışlı metinler.
- UUID v4 ve v7 seçimi: JavaScript/Python örnekleri, Python sürüm gereksinimi ve sıralama davranışındaki farklar.

Rehberler, örnekleri denemek için ilgili tarayıcı araçlarına bağlanıyor. Bu araçların hash hesaplama, Unicode dönüştürme ve UUID üretme işlemleri tarayıcıda çalışıyor.

Rehberler: https://devstools.app/guides
