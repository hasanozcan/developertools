**DevsTools** ([devstools.app](https://devstools.app)) is an ultra-fast suite of **366 online developer tools** running **100% client-side** in your browser. No paywalls, no mandatory signups, zero server tracking.

---

## 🌟 Key Features

- 🔒 **100% Client-Side Privacy:** Your tokens, API keys, JSON payloads, images, PDFs, and source code never leave your browser.
- ⚡ **Instant Execution:** Built with Next.js 16 Static Site Generation (SSG) with zero backend round-trip latency.
- 🔍 **Keyboard-First Navigation:** Press `/` anywhere to open the command palette fuzzy search.
- 🌙 **Dark & Light Modes:** Sleek, accessible UI designed with Tailwind CSS and WCAG 2.1 AA compliance.
- 🌍 **7 Languages Supported:** English, Türkçe, Deutsch, Español, Français, Русский, 简体中文.
- 🧪 **Rock-Solid Reliability:** 977 Unit Tests across 371 test suites and full Playwright E2E test coverage.

## 🛠️ Tool Catalog by Category (366 Tools)

### 1. Converters (105 Tools)
- **cURL & API Converters**: Transform cURL commands into modern TypeScript/JavaScript Axios requests, Fetch to cURL terminal commands, Python Requests/HTTPX, Go, Rust, and C#.
- **Document & Spreadsheet Converters**: Excel (XLSX, CSV, TSV) to JSON, JSON to Excel/CSV with nested flattener, JSON to XML, and Images (JPG/PNG/WebP) to Multi-Page PDF.
- **Media Converters**: All-in-One Image Format Converter (PNG ↔ JPG ↔ WebP ↔ AVIF ↔ BMP ↔ ICO).
- **Data & Schema Converters**: JSON to Python Dataclass, Go Struct, Kotlin Data Class, Swift Struct, C# Class, and Protocol Buffers to TypeScript interfaces.
- Plus 89 additional converters (Zod ↔ JSON Schema, SVG to React Native, YAML, CSV, TSV, GraphQL, etc.).

### 2. Developer Utilities (90 Tools)
- **AI & LLM Tools**: All-in-One LLM Token & Pricing Calculator (OpenAI, Claude, Gemini, DeepSeek, Llama), Embedding Cost Estimator, Token Counters, and RAG visualizers.
- **Sandboxes & Editors**: Live HTML/CSS/JS Sandbox & Code Playground with Tailwind CDN support, responsive viewports, and console inspector.
- **Media & Document Utilities**: Client-side Image Compressor & Optimizer, Image Color Palette Extractor & Pixel Eyedropper, PDF Merger & Combiner, and PDF Splitter & Page Range Extractor.
- **DevOps & Cloud**: Kubernetes Resource Calculator, Terraform HCL to JSON Parser, and Gitignore Tester.
- Plus 80 additional developer utilities (SemVer, IPv6 Subnet, DNS Simulator, WebSocket Tester, etc.).

### 3. Generators (66 Tools)
- **SEO & Web**: Schema.org JSON-LD Structured Data Builder (FAQPage, Article, Product, Organization, LocalBusiness), Next.js App Router metadata generator, and Open Graph previewer.
- **AI Tool Builders**: Anthropic Claude Tool builder, OpenAI Structured Outputs JSON schema generator, and LangGraph state graph generator.
- **Security & Testing**: NanoID custom alphabet generator, and Luhn-compliant test credit card generator for sandbox testing.
- Plus 56 additional generators (Shadcn UI Theme, OKLCH Palette, GitHub Actions Matrix, Wrangler Config, Ollama Modelfile, etc.).

### 4. Cryptography & Security (37 Tools)
- **File & Privacy Security**: Multi-Hash File Checksum & Comparator (MD5, SHA-1, SHA-256, SHA-512, CRC32) with drag-and-drop verification, and Image EXIF Metadata Viewer & Stripper.
- **Cryptographic Hashes**: SHA-3 (Keccak-256 / SHA3-512) Hash Generator, Ethereum Keccak-256 Hasher, and UUID v5 Generator.
- Plus 31 security tools (Argon2, Bcrypt, RSA Keypair, Ed25519, PGP Inspector, SSH Key Inspector, Webhook Signature Verifier, etc.).

### 5. Code Formatters (20 Tools)
- **SQL Keyword Uppercaser**: Capitalize SQL keywords while preserving column names and string literals.
- Plus 19 formatters (SQL Minifier, Nginx, Terraform, Protobuf, TOML, Docker Compose, Apache, Package.json, GraphQL, HTML, CSS, JS, etc.).

### 6. Text Tools (17 Tools)
- **AI Agent Prompt Optimizer**: Structure autonomous AI agent persona, constraints, and goal instructions.
- **SQL Identifier Slugifier**: Convert text into valid snake_case SQL table and column identifiers.
- Plus 15 text tools (Word Counter, Text Diff, Sort Lines, Remove Duplicates, Text Obfuscator, etc.).

### 7. Encoders & Decoders (17 Tools)
- **Crypto & Unit Converters**: Ethereum Wei/Gwei/Ether & Bitcoin Satoshi unit converter.
- **Base Encoders**: Base64URL, Base64, Base32, Base58, Hex, Binary, URL, Unicode Escape, and HTML Entities.
- Plus 7 encoding tools (Quoted-Printable MIME, Morse Code Audio Player, etc.).

### 8. JSON Tools (14 Tools)
- **JSON Deep Flattener**: Flatten deeply nested JSON objects into single-level dot notation keys.
- **RFC 6902 JSON Patch Builder**: Generate standard JSON patch differential operations between two objects.
- Plus 12 JSON tools (JSON Formatter, Validator, JSON to CSV, Diff & Patch, JSON Pointer, Size Analyzer, etc.).
