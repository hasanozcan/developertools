**DevsTools** ([devstools.app](https://devstools.app)) is an ultra-fast suite of **350 online developer tools** running **100% client-side** in your browser. No paywalls, no mandatory signups, zero server tracking.

---

## 🌟 Key Features

- 🔒 **100% Client-Side Privacy:** Your tokens, API keys, JSON payloads, and source code never leave your browser.
- ⚡ **Instant Execution:** Built with Next.js 16 Static Site Generation (SSG) with zero backend round-trip latency.
- 🔍 **Keyboard-First Navigation:** Press `/` anywhere to open the command palette fuzzy search.
- 🌙 **Dark & Light Modes:** Sleek, accessible UI designed with Tailwind CSS and WCAG 2.1 AA compliance.
- 🌍 **7 Languages Supported:** English, Türkçe, Deutsch, Español, Français, Русский, 简体中文.
- 🧪 **Rock-Solid Reliability:** 929 Unit Tests across 355 test suites and full Playwright E2E test coverage.

## 🛠️ Tool Catalog by Category (350 Tools)

### 1. Converters (98 Tools)
- **cURL Converters Suite**: Transform cURL commands into Python Requests, JavaScript/Fetch, Go net/http, Rust reqwest, PHP cURL, C# HttpClient, Java HttpClient, and Vercel AI SDK.
- **Data & Schema Converters**: JSON to Python Dataclass, Go Struct, Kotlin Data Class, Swift Struct, C# Class, and Protocol Buffers to TypeScript interfaces.
- **Modern Web Migrators**: Tailwind CSS v3 to v4 Migrator, CSS box-shadow to Tailwind class converter, and HTML Table to Markdown/JSON/CSV converters.
- **Database Translators**: SQL to Prisma Schema, SQL to Drizzle Schema, SQL to Django ORM, and MongoDB queries to SQL.
- Plus 82 additional converters (Zod ↔ JSON Schema, SVG to React Native, YAML, CSV, TSV, GraphQL, etc.).

### 2. Developer Utilities (84 Tools)
- **AI & LLM Tools**: Embedding Cost & Latency Estimator, DeepSeek & Claude Token Counters, Tiktoken BPE visualizer, MCP Inspector, and RAG semantic chunking visualizers.
- **DevOps & Cloud**: Kubernetes CPU/Memory Resource Calculator, Terraform HCL to JSON Parser, Gitignore Tester & Matcher, and Subnet/CIDR Calculators.
- **Database & Query**: PostgreSQL EXPLAIN / EXPLAIN ANALYZE visualizer and query plan cost analyzer.
- **Networking & Web**: DNS Record Propagation Checker, Google Analytics UTM Campaign URL Builder, and HTTP Headers to JSON parser.
- Plus 74 additional developer utilities (SemVer, IPv6 Subnet, DNS Simulator, WebSocket Tester, etc.).

### 3. Generators (65 Tools)
- **AI Tool Builders**: Anthropic Claude Tool / Function Calling schema builder, OpenAI Structured Outputs JSON schema generator, and LangGraph state graph definition generator.
- **Modern Frontend**: Next.js App Router metadata generator (`generateMetadata`), SVG to CSS data URI generator, and Tailwind fluid spacing scale generator.
- **Backend & DevOps**: Systemd Timer unit generator (`.timer` & `.service`), Docker Compose `.env` template generator, and JWT builder with HMAC signature simulation.
- **Security & Testing**: NanoID custom alphabet generator, and Luhn-compliant test credit card number generator for sandbox testing.
- Plus 55 additional generators (Shadcn UI Theme, OKLCH Palette, GitHub Actions Matrix, Wrangler Config, Ollama Modelfile, etc.).

### 4. Cryptography & Security (35 Tools)
- **Cryptographic Hashes**: SHA-3 (Keccak-256 / SHA3-512) Hash Generator, Ethereum Keccak-256 Hasher, and UUID v5 (SHA-1 namespace) Generator.
- **Key & Secret Management**: BIP-39 12/24-word Mnemonic Seed Phrase Generator, Diceware Passphrase Wordlist Generator, and EIP-712 Typed Data Hasher.
- Plus 29 security tools (Argon2, Bcrypt, RSA Keypair, Ed25519, PGP Inspector, SSH Key Inspector, Webhook Signature Verifier, etc.).

### 5. Code Formatters (20 Tools)
- **SQL Keyword Uppercaser**: Capitalize SQL keywords while preserving column names and string literals.
- Plus 19 formatters (SQL Minifier, Nginx, Terraform, Protobuf, TOML, Docker Compose, Apache, Package.json, GraphQL, HTML, CSS, JS, etc.).

### 6. Text Tools (17 Tools)
- **AI Agent Prompt Optimizer**: Structure autonomous AI agent persona, constraints, and goal instructions.
- **SQL Identifier Slugifier**: Convert text into valid snake_case SQL table and column identifiers.
- Plus 15 text tools (Word Counter, Text Diff, Sort Lines, Remove Duplicates, Text Obfuscator, etc.).

### 7. Encoders & Decoders (17 Tools)
- **Crypto & Unit Converters**: Ethereum Wei/Gwei/Ether & Bitcoin Satoshi unit converter.
- **Base Encoders**: Base64URL, Base64, Base32, Base58, Hex, Binary, URL, Unicode Escape, and HTML Entities.
- Plus 7 encoding tools (Quoted-Printable MIME, Morse Code Audio Player, etc.).

### 8. JSON Tools (14 Tools)
- **JSON Deep Flattener**: Flatten deeply nested JSON objects into single-level dot notation keys.
- **RFC 6902 JSON Patch Builder**: Generate standard JSON patch differential operations between two objects.
- Plus 12 JSON tools (JSON Formatter, Validator, JSON to CSV, Diff & Patch, JSON Pointer, Size Analyzer, etc.).
